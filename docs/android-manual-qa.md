# Android 디자인 미리보기 — 실기기 검증 체크리스트

## 검증 범위
이 체크리스트는 **테스트 APK**를 대상으로 합니다. GitHub Actions의 APK 빌드 성공이나 브라우저 스모크 테스트만으로 실제 휴대전화 기능이 검증된 것으로 간주하지 않습니다.

- 다운로드: https://github.com/stevejjobs8/where-are-you/releases/download/app-design-preview/where-are-you-design-preview.apk
- 패키지: `io.github.stevejjobs8.whereareyou.designpreview` (정식 앱과 별도 설치)
- UI: `app-design-preview.html`; 지도: `map-design-preview.html` (GitHub Pages에서 제공)
- 실사용 위치 전송과 짝꿍 연결을 시험할 때는 반드시 당사자 모두 동의한 기기로 진행합니다.

## A. 화면 및 조작
- [ ] Android 앱 설치 및 첫 실행 시 화면이 깨지지 않음
- [ ] 이름 입력, 위치 공유 동의, 권한 안내가 순서대로 진행됨
- [ ] 짝꿍이 없는 상태에서 지도 대신 연결 안내가 나타남
- [ ] 짝꿍을 연결한 후 3D 디오라마가 화면 중심에 표시됨
- [ ] 상단 이름/상태와 말풍선이 겹치지 않음
- [ ] 메뉴를 열고 닫을 수 있으며 Android 뒤로가기가 정상 동작함
- [ ] 화면 회전/기울이기 제스처가 의도대로 작동함
- [ ] 지도 및 앱의 텍스트·버튼이 화면 하단 시스템 탐색바에 가려지지 않음

## B. 위치 상태·개인정보
- [ ] 한쪽에서 공유를 중지하면 상대방에게 이전 좌표가 계속 노출되지 않음
- [ ] 새 위치가 5분 이상 들어오지 않을 때 마지막 지도를 숨기고 갱신 중단을 알림
- [ ] 지하철 경로 추정 상태를 실제 GPS 측정 상태와 구분해서 표시
- [ ] 연결이 끊겨도 가짜 실제 위치로 자동 전환되지 않음
- [ ] 연결 해제 후 상대방 위치가 더 이상 표시되지 않음

## C. 백그라운드·이동
- [ ] 공유를 켠 뒤 Android 알림에 위치 공유 서비스가 표시됨
- [ ] 화면을 끄고 다시 켠 뒤에도 공유 상태가 일관됨
- [ ] 정지 중 GPS 흔들림이 과도하게 화면에 반영되지 않음
- [ ] 도보·버스·지하철 시연과 실제 이동 상태가 혼동되지 않음
- [ ] 지도 데이터를 받지 못할 때 오류/빈 상태가 이해 가능하게 표시됨
- [ ] 배터리 소모와 발열이 일상 사용에 적합한 수준인지 별도로 측정
