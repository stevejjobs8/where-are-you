위치기반서비스 이용약관개인정보처리방침

위치기반서비스 이용약관

제1조 (목적)

이 약관은 "지금 너는 어디쯤"(이하 "서비스")이 제공하는 위치기반서비스를 이용할 때 서비스 제공자와 이용자의 권리, 의무 및 책임을 정해요.

제2조 (서비스 내용)

서비스는 이용자가 위치 공유를 켠 동안 이용자 휴대폰의 위치를 수집해, 이용자가 직접 연결한 짝꿍 한 명에게 미니어처 지도 형태로 보여줘요. 짝꿍은 앱 또는 짝꿍이 앱으로 인증해 연결한 웹 브라우저에서만 위치를 볼 수 있어요.

제3조 (이용 연령)

만 14세 미만은 서비스를 이용할 수 없어요.

제4조 (위치정보의 수집과 이용)

  • 수집 항목: 위도·경도, 정확도, 속도, 이동 방향, 휴대폰 센서가 판단한 이동 상태(정지·걷기·차량 등), 갱신 시각
  • 수집 방법: 이용자가 앱에서 공유를 켠 동안 휴대폰의 위치 기능으로 수집
  • 보관: 서버에는 가장 최근 위치 1건만 저장하고, 공유를 끄면 좌표를 즉시 지워요. 이동 경로는 저장하지 않아요.

제5조 (개인위치정보의 제3자 제공과 통보)

서비스는 이용자의 동의를 받아, 이용자가 연결한 짝꿍에게만 개인위치정보를 제공해요. 짝꿍이 위치를 본 횟수는 날짜별로 기록하고, 이용자의 동의에 따라 30일 범위 안에서 모아서 앱에서 알려드려요.

제6조 (위치정보 이용·제공 사실 확인자료의 보존)

제공 사실 확인자료(누가 언제 몇 번 봤는지)는 6개월간 보관한 뒤 자동으로 지워요.

제7조 (이용자의 권리)

  • 언제든 공유를 끄거나, 짝꿍 연결을 끊거나, 연결된 웹 브라우저를 모두 끊을 수 있어요.
  • 앱의 "더보기 → 내 정보 완전히 삭제"로 위치, 이름, 짝꿍 연결, 열람 기록을 즉시 모두 지울 수 있어요.
  • 동의를 철회하면 해당 정보를 지체 없이 파기해요.

제8조 (사업자 정보와 문의)

사업자명, 주소, 연락처, 위치정보관리책임자: 출시 전 기재 예정

개인정보처리방침

1. 처리하는 개인정보

  • 앱에서 입력한 이름(별명), 기기별로 무작위 생성되는 식별 코드
  • 위치정보: 위 약관 제4조의 항목
  • 열람 기록: 짝꿍이 위치를 본 날짜와 횟수
  • 웹 연결 기록: 연결한 브라우저 종류, 마지막 접속 시각

2. 처리 목적

연결된 짝꿍에게 위치를 보여주는 기능과, 법에서 정한 제공 사실 통보·보존 의무를 위해서만 써요. 광고나 분석에 쓰지 않고, 짝꿍 외의 제3자에게 제공하지 않아요.

3. 보유 기간과 파기

  • 위치: 최근 1건, 공유를 끄면 즉시 삭제
  • 열람 기록: 6개월 후 자동 삭제
  • 웹 연결: 90일 동안 쓰지 않으면 만료
  • 이용자가 삭제를 요청하면 모든 정보를 즉시 파기

4. 처리 위탁과 국외 이전

데이터 저장은 Supabase(데이터베이스 서비스)를, 지도 화면 제공은 GitHub Pages와 OpenFreeMap을 이용해요. 각 서비스의 서버 위치와 위탁 내용은 출시 전 확정해 기재할 예정이에요.

5. 안전성 확보 조치

  • 위치 표는 직접 접근을 막고, 본인 확인용 쓰기 열쇠를 가진 기기와 연결된 짝꿍만 접근할 수 있는 함수로만 읽고 써요.
  • 짝꿍 연결과 웹 연결은 10분짜리 1회용 8자리 코드로만 이뤄져요.
  • 통신은 모두 HTTPS로 암호화돼요.
