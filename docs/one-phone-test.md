# 한 대의 Android 휴대전화로 검증하기

## 1. 1인 시연 (실제 좌표 전송 없음)
최신 테스트 APK: https://github.com/stevejjobs8/where-are-you/releases/download/app-design-preview/where-are-you-design-preview.apk

- 앱을 설치해 실행합니다. 새 설치에서 **혼자 체험하기**가 기본 시작 화면입니다.
- 지도 화면에서 걷기, 달리기, 자전거, 버스, 지하철, 쉬기를 선택합니다.
- 맑음/비/눈을 눌러 효과를 확인합니다.
- 지도에 직접 손가락을 대고 회전/기울이기를 조작합니다.
- 상단 이름·상태, 지도 말풍선, 하단 공유 UI가 화면 밖으로 나가지 않는지 확인합니다.
- **1인 시연 중에는 Supabase 계정·위치 서버 호출이 차단됩니다.** 시연 지형 지도 및 공개 지도 타일은 네트워크에서 불러옵니다.

앱 설치 없이 브라우저에서 확인할 수도 있습니다:
https://stevejjobs8.github.io/where-are-you/app-design-preview.html?preview=main&solo=1

## 2. 한 기기에서 실제 공유/수신 통합 테스트
두 앱의 패키지와 저장소가 분리되어 있어, 한 휴대전화에서 각각 독립 사용자로 설정할 수 있습니다.

- 기존 앱 (A): https://github.com/stevejjobs8/where-are-you/releases/download/app-latest/app-debug.apk
- 디자인 미리보기 앱 (B): https://github.com/stevejjobs8/where-are-you/releases/download/app-design-preview/where-are-you-design-preview.apk

1. A를 실행해 사용자 A의 이름을 설정합니다.
2. B에서 **연결 시험**을 눌러 실제 연결 화면으로 전환하고, 사용자 B의 이름으로 온보딩합니다.
3. A의 **짝꿍 연결**에서 초대 코드를 생성합니다.
4. B의 **짝꿍 연결**에서 A가 생성한 코드를 입력합니다.
5. 두 앱에서 위치 공유를 각각 켜고 위치·알림 권한을 승인합니다.
6. 앱을 번갈아 열어 서로의 위치와 최신 갱신 상태를 확인합니다.
7. A에서 위치 공유를 끄고 B에서 이전 위치가 사라지는지 확인합니다.
8. B의 **더보기 → 혼자 체험하기**를 누르면 실제 위치 공유를 중단하고 시연 화면으로 돌아갑니다.

**중요:** 한 기기에서 두 앱 모두 동일한 실제 GPS 좌표를 사용하므로, 두 사람이 서로 다른 장소에 있을 때의 지도 동작이나 실제 도보/버스/지하철 판정은 검증되지 않습니다. 이 결과를 2기기 실사용 검증으로 대체해서는 안 됩니다.

## 검증 시 개인정보
- 공개 화면 캡처에 실제 GPS 주소, 초대 코드, 인증 키가 노출되지 않도록 주의합니다.
- 가능하면 실제 외부 상대방이 없는 테스트 계정으로만 진행합니다.
- 테스트 후 두 앱의 위치 공유를 꺼둡니다.
